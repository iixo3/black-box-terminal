# Bundled typefaces

Outfit is the prototype default (chosen 2026-10-24). Manrope and Space Grotesk remain available in the temporary comparison control. Fonts are served locally with the prototype. Unmodified variable TTFs from the official [Google Fonts repository](https://github.com/google/fonts): [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit).

Each family includes its SIL Open Font License. `sources.json` records source URLs, byte counts and SHA-256 hashes fetched 2026-10-23. No system font installation or runtime Google Fonts request is required.
